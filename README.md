## Terbitkan menggunakan GitHub Pages
1. Cipta repositori GitHub bernama `cs-meaningfulliving` (atau nama pilihan yang tersedia).
2. Muat naik semua fail dan folder dalam projek ini ke root repositori.
3. Buka **Settings → Pages**.
4. Pilih **Deploy from a branch**, branch `main`, folder `/ (root)`, kemudian Save.
5. URL bergantung pada nama akaun dan jenis repositori. Untuk repositori projek, bentuk lazimnya `https://NAMA-AKAUN.github.io/NAMA-REPOSITORI/`.

## Domain sendiri
